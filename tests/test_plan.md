# Checklist Breve de Pruebas y Entrega

## 1) Checklist de pruebas mínimas
- [ ] Ejecuté al menos un caso nominal.
- [ ] Ejecuté al menos un caso con error controlado.
- [ ] Registré resultados esperados y obtenidos.

## 2) Checklist de documentación
- [ ] Completé `docs/propuesta.md`.
- [ ] Completé `docs/caso_de_uso.md`.
- [ ] Revisé `docs/estructura_repositorio.md` y lo alineé con mi proyecto.
- [ ] Completé `docs/plan_de_pruebas.md`.

## 3) Checklist de ejecución
- [ ] Verifiqué que `scripts/run.sh` funciona en mi entorno.
- [ ] Confirmé que existe `src/main.<ext>` según mi lenguaje.
- [ ] Validé que la salida del prototipo corresponde al objetivo.

## 4) Checklist de entrega final
- [ ] Mi proyecto se mantiene pequeño y viable.
- [ ] No usé frameworks ni dependencias complejas.
- [ ] No usé nube, APIs externas, bases de datos ni Docker.
- [ ] Mi repositorio está ordenado y listo para revisión en GitHub Classroom.
